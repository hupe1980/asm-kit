asm-rs assembles text into machine code for six targets behind one API. These
pages cover how to drive it, what it accepts, and how it works inside.

New here? Start with the [Getting Started](@/docs/getting-started.md) guide, then
keep [Configuration](@/docs/configuration.md) open — it is the reference for
syntax dialects, directives and limits.

For the generated Rust API — every type, method and doc-test — see
[docs.rs/asm-rs](https://docs.rs/asm-rs).
